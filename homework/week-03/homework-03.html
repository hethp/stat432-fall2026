Question 2: Ridge regression with nearly collinear predictors

Part (a)

After generating X with seed 43231, centering and standardizing each column to have mean zero and average squared value one:

  • Correlation between X1 and X2: 0.9983
  • Largest singular value of X: 14.173
  • Smallest singular value of X: 0.4061

The first two predictors are constructed as Xi1 = Li + 0.04Ui1 and Xi2 = Li + 0.04Ui2, sharing a common latent variable L with only small independent perturbations. Their correlation is approximately 0.998.

The sum direction X1 + X2 is well-observed because both columns move together, so the corresponding singular value is large. The difference direction X1 − X2 is nearly zero, so the corresponding singular value is small (approximately 0.41). The ridge formula is

β̂λ = (XTX + nλIp)−1XTỹ.

The OLS estimator amplifies noise in directions with small singular values. Since the difference direction has a singular value about 35 times smaller than the sum direction, the contrast β̂1 − β̂2 is estimated from a nearly degenerate direction and is therefore much more variable than β̂1 + β̂2.

Part (c)

Under OLS (λ = 0), the individual coefficients β̂1 and β̂2 each have standard deviations near 1.8, and their difference has a standard deviation near 3.6. This extreme variability arises because the near-collinearity of the first two predictors makes it hard to separate their individual contributions. Their means are near the true values on average, so OLS is approximately unbiased, but the variance is enormous.

Ridge with λ = 0.02 dramatically reduces the standard deviations of the individual coefficients to about 0.15 and the difference to about 0.27, while the sum remains nearly unchanged (mean ≈ 2.96 versus true 3.0, SD ≈ 0.10). This moderate penalty shrinks the weakly identified difference direction toward zero without substantially distorting the well-identified sum. The test MSE drops from about 1.04 to 1.03, a modest improvement reflecting the variance reduction.

Ridge with λ = 0.2 shrinks more aggressively: the individual coefficient SDs fall below 0.05 and the difference is essentially zero (SD ≈ 0.03). However, the sum is noticeably biased (mean ≈ 2.72 versus true 3.0), and the test MSE increases to about 1.13. The additional bias now outweighs the further variance reduction.

Ridge can substantially stabilize the individual coefficients without producing an equally large change in the fitted values because the fitted values depend on Xβ̂, and the sum direction X1 + X2 dominates the prediction. Shrinking the difference β̂1 − β̂2 toward zero has a large effect on the individual coefficient estimates but a negligible effect on the predicted values, since the difference direction carries almost no signal in the predictor space.

Question 3: What does ridge regression shrink?

Part (a)

Differentiate the ridge objective with respect to β:

∇Lλ(β) = −(1/n)XT(ỹ − Xβ) + λβ.

Setting the gradient equal to zero gives

(1/n)XTXβ̂λ + λβ̂λ = (1/n)XTỹ.

Multiplying both sides by n yields the ridge normal equation:

(XTX + nλIp)β̂λ = XTỹ.

For any nonzero vector a ∈ ℝp,

aT(XTX + nλIp)a = ‖Xa‖22 + nλ‖a‖22 > 0

when λ > 0. The matrix is therefore positive definite and invertible, regardless of the rank of X or whether p > n. This guarantees a unique solution.

Part (b)

Using the compact SVD X = UrDrVrT, the ridge solution becomes

β̂λ = Vr(Dr2 + nλIr)−1DrUrTỹ.

Multiplying by X gives the fitted values:

Xβ̂λ = ∑j=1r [dj2 / (dj2 + nλ)] ujujTỹ.

Thus, the fitted response component in the jth left singular-vector direction is multiplied by the shrinkage factor ρj(λ) = dj2 / (dj2 + nλ).

With n = 100, λ = 0.01, and nλ = 1:

  • ρ1 = 100 / 101 ≈ 0.9901
  • ρ2 = 4 / 5 = 0.8000
  • ρ3 = 0.04 / 1.04 ≈ 0.0385

The total effective degrees of freedom, including the unpenalized intercept:

dfeff(0.01) = 1 + 0.9901 + 0.8000 + 0.0385 ≈ 2.8286.

Part (c)

The third direction (d3 = 0.2) receives the strongest shrinkage, with ρ3 ≈ 0.0385. Its small singular value means the data provide little information in that direction, so the unregularized OLS estimate can have high variance. Shrinkage reduces this sensitivity to response noise, substantially lowering prediction variance.

However, if the true mean response has a large component in the third left singular-vector direction, reducing that component to about 3.85% of its OLS value introduces substantial prediction bias. The bias-variance tradeoff is favorable when the true signal is small in weakly observed directions but unfavorable when it is large.

Question 4: Ridge regression and optimization

Part (a)

The eigenvalues of A0 = (1/n)XTX are 9 and 0.01. The condition number is the ratio of the largest to the smallest eigenvalue:

κ(A0) = 9 / 0.01 = 900.

Adding λ = 0.09 shifts both eigenvalues: 9 + 0.09 = 9.09 and 0.01 + 0.09 = 0.10. Therefore,

κ(Aλ) = 9.09 / 0.10 = 90.9.

The condition number drops from 900 to 90.9. This means the contour ellipses of the ridge objective are much less elongated than those of the OLS objective. The geometry becomes more nearly circular, which improves both numerical conditioning and the convergence behavior of iterative solvers.

Part (b)

Because the ridge objective is quadratic, the gradient at β(k) can be written as

∇Lλ(β(k)) = Aλe(k),

where e(k) = β(k) − β̂λ. The gradient descent update gives

e(k+1) = (Ip − ηAλ)e(k).

In an eigendirection with unpenalized eigenvalue a, Aλ has eigenvalue a + λ. The error component in that direction is multiplied by 1 − η(a + λ) at each step.

Convergence interval: Every direction contracts when |1 − η(a + λ)| < 1 for all eigenvalues. This requires 0 < η < 2/M = 2/9.09 ≈ 0.2200.

Choice η = 1/M = 1/9.09:

  • Strong direction (a + λ = 9.09): contraction factor = 1 − 9.09/9.09 = 0. The error vanishes in one step.
  • Weak direction (a + λ = 0.10): contraction factor = 1 − 0.10/9.09 ≈ 0.9890. This direction converges very slowly.

The strong direction converges instantly, but the weak direction barely contracts each step. The convergence bottleneck is the small eigenvalue direction.

Choice η = 2.1/M = 2.1/9.09:

  • Strong direction: contraction factor = 1 − 2.1 × 9.09/9.09 = 1 − 2.1 = −1.1.

The magnitude |−1.1| = 1.1 > 1. Since the initial error has a nonzero component in this eigendirection (as stated), the error alternates in sign and grows unboundedly. The method does not converge, even though the weak-direction component may still contract.

Part (c)

Increasing λ improves the condition number of Aλ, making gradient descent converge faster. However, the penalty parameter λ defines the statistical estimator, not just the optimization problem. A larger λ shrinks the coefficients more, reducing variance but introducing more bias.

Choosing λ to make gradient descent converge quickly is a purely computational criterion that ignores the statistical bias-variance tradeoff. The resulting model could have excessive bias and poor prediction accuracy. The penalty should be selected using statistical criteria such as cross-validation or GCV that assess prediction quality, not by optimizing the speed of the numerical solver.

Ten-fold cross-validation was performed over the penalty grid Λ = {0} ∪ {10−4+0.05l : l = 0, …, 120}, using the supplied fold assignments. Predictor means and scales were estimated separately within each set of nine training folds.

The CV-minimum and GCV ridge fits use mild shrinkage (effective df ≈ 6.8 and 6.7, respectively) and achieve very similar test errors (66.0 and 65.9), slightly lower than OLS (66.3). The one-standard-error model applies much stronger regularization (effective df ≈ 3.0), which raises both training MSE (100.4) and test MSE (81.2) substantially.

The observed ordering of test MSEs does not authorize choosing the GCV model after viewing this table. The three penalty rules were selected using training information only. The test set provides a single final assessment of those procedures. Selecting the model with the smallest observed test MSE after seeing the results would turn the test set into another validation set, making that minimum appear more favorable than it would be on new data. This violates the separation between model selection and model evaluation.

Additionally, GCV is not an independent test result—it estimates prediction error from the training fit by correcting the training residuals using effective degrees of freedom. Ridge regression controls coefficient variability within the specified linear model but does not correct for nonlinear structure, omitted variables, or other forms of model misspecification.
