Question 1: Choosing an SVM Kernel

Setup

Data: saheart.csv with n = 462 observations and p = 9 predictors. Response: chd (coronary heart disease, binary). famhist coded as 1 = Absent, 2 = Present. All other predictors are numerical.

I compared SVMs with five kernel types: linear, polynomial with degrees 2, 3, and 4, and radial basis function (RBF). I selected 20 candidate settings total by varying the cost parameter C across each kernel and the scale parameter γ for the RBF kernel. For all polynomial kernels I fixed coef0 = 1 and gamma = 'scale'.

I created five folds by shuffling the observation indices with np.random.seed(432) and splitting into five roughly equal groups. Every candidate was evaluated on the same five folds. Within each fold, predictors were standardized using only the training observations from that fold.

Preferred kernel and justification

I prefer the RBF kernel with C = 10 and γ = 0.01, which achieved the lowest mean 5-fold CV misclassification rate of 0.2642. The linear kernel performed reasonably well (best linear CV error: 0.2815 at C = 0.1), suggesting some approximate linear separability, but the RBF kernel's additional flexibility reduced the error by about 1.7 percentage points. The polynomial kernels did not outperform either the linear or RBF options; the degree-2 polynomial at C = 1 reached 0.2772 but still trailed the best RBF. Higher-degree polynomials (d = 3, 4) tended to overfit, especially at large C. The small γ = 0.01 value for the selected RBF indicates a wide kernel that generalizes well without overfitting.

Selected model: RBF kernel with C = 10 and γ = 0.01 (CV error = 0.2642). This was the lowest CV error among all 19 candidates. The RBF kernel with a small γ produces wide, smooth decision boundaries that generalize better than the polynomial alternatives, which tended to overfit at higher degrees or large C.

Interpretation. The best model misclassifies about 26.4% of observations in cross-validation. This moderate error rate likely reflects the inherent difficulty of predicting CHD from these risk factors alone. Linear SVMs were competitive (best 0.2815), suggesting the classes are not far from linearly separable. Limitations include the small sample size relative to the complexity of RBF, and the absence of a separate held-out test set in this analysis (all evaluation is via CV).

# SVM Classification Analysis Skill

## Inputs (supplied at invocation)
Dataset path, response column, predictor columns, and any factor codings.

## Workflow

### 1. Data screening
Check suitability for SVM: enough observations relative to predictors, no
constant columns, class balance (flag if minority class < 15 %). Encode
categorical predictors numerically. Report n, p, and class distribution.

### 2. Kernel selection
Consider at least: **linear**, **polynomial (degree 2–3)**, and **RBF**.
Justify which are worth trying given n and p.

### 3. Tuning parameters
For each kernel, vary cost C (e.g., 0.01, 0.1, 1, 10, 100). For RBF,
also vary gamma. For polynomial kernels, fix coef0 = 1, gamma = 'scale'.
Keep total candidates ≤ 25.

### 4. Evaluation and model selection
Create five folds; use the **same folds for every candidate**. Standardize
predictors inside each fold (fit on training portion only). Compute mean
CV misclassification rate. Select the lowest; break ties by preferring the
simpler kernel (linear > polynomial > RBF).

### 5. One-page report (11-point font)
1. **Table** of all candidates with mean CV misclassification rates.
2. **Figure** (bar or dot plot) of CV error by candidate.
3. **Selected model**: kernel, tuning parameters, brief justification.
4. **Key results**: CV error of selected model; test error if applicable.
5. **Interpretation**: strengths, weaknesses, limitations (2–3 sentences).

Keep prose concise. Prefer numbers and visuals over long paragraphs.
